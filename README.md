# WCAG・JIS参照データセット

WCAGとJIS X 8341-3を版ごとに参照し、日本語名称の変遷を追えるデータセットを検討するリポジトリです。将来のチェックリスト、報告書、MCPなどが同じデータを利用することを想定しています。

現在は[設計案](docs/dataset-proposal.md)に基づく最初のデータ本体を収録しています。[データの読み方](data/README.md)と[117項目の一覧](data/catalog.csv)から確認できます。

独自のコードと説明文には[MITライセンス](LICENSE)を適用します。収録したW3C・WAIC由来の内容には各出典の利用条件が適用されます。対象範囲と出典は[権利表示と出典](THIRD_PARTY_NOTICES.md)を確認してください。

## AIで使う

達成基準番号が分かる場合は、参照ツールから名称・本文・版間の関係・出典URLをまとめて取得できます。JSON出力はAIへの入力や、小規模なRAGの検索結果として使えます。初回の依存ライブラリの導入は[メンテナンスガイド](docs/maintenance.md#準備)を参照してください。

```bash
python3 tools/show_criterion.py 2.4.6 --format json
```

番号が分からない質問にも対応したい場合は、名称と本文を検索用に索引化し、見つかった番号をこの参照ツールで再取得する構成が使えます。回答には規格の版、文書の位置づけ、原文へのリンクを添えてください。ウェブページへの適用や適合の判定には、ページ固有の証拠と人による確認が必要です。

使い方、RAG用のデータ構成、AIへの指示例は[AI活用ガイド](docs/ai-usage.md)にまとめています。

## データ本体

`data/` には、WCAG 2.2の原則・ガイドライン・達成基準・適合要件の117項目、旧版とJIS X 8341-3:2016の項目、各名称、本文、対応関係を収録しました。WAIC解説書は `wcag22-202609` タグが付いたコミットに固定しています。このデータセットはJIS達成基準名の公開条件などを確認中のため、公開前のドラフトです。JIS本文は収録していません。

生成方法と収録範囲は[データのREADME](data/README.md)に記載しています。

WCAG 2.2解説書は、[日英の資料スナップショット](data/understanding/README.md)として別に収録しました。翻訳元の版、画像、出典、公開前の確認事項はそちらに記載しています。

## 達成基準を調べる

番号を指定すると、各版の名称・状態、収録済みの本文、版間の対応関係、日英解説書の出典URLをまとめて表示できます。上記のコマンドから `--format json` を外すと、端末で読みやすい形式になります。

端末表示の本文はHTMLから抽出したプレーンテキストです。箇条書きなどの構造と正確な文言を確認するときは、併記された原文のURLを参照してください。JISの名称は手元資料由来で、正式文書との照合は未完了です。
